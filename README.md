## 📖 What is This? / 这是什么？

<table>
<tr>
<td width="50%">

**English**

**ReadmeForge** is a CLI tool that generates stunning **GitHub Profile READMEs** in seconds.

Answer a few questions → Get a beautiful, professional profile page with stats cards, skill badges, contribution graphs, and auto-update via GitHub Actions.

> 💡 **Your GitHub Profile is your tech resume. Make it unforgettable.**

</td>
<td width="50%">

**中文**

**ReadmeForge** 是一个命令行工具，帮你一键生成惊艳的 **GitHub Profile README**。

回答几个简单问题 → 获得专业美观的个人主页，包含统计卡片、技术徽章、贡献图表，还能设置 GitHub Action 每日自动更新。

> 💡 **GitHub 个人主页就是你的技术名片。为什么不让它令人难忘？**

</td>
</tr>

## 📦 Installation / 安装

### Prerequisites / 前置要求

**Node.js** >= 18.0.0

### Install / 安装

```bash
# Global install / 全局安装
npm install -g readmeforge

# Or use directly / 或直接使用
npx readmeforge
```

---

## 🚀 Usage / 使用方法

### 1. Interactive Mode / 交互模式

```bash
readmeforge
```

Choose your language, answer a few questions, done! / 选语言，回答问题，搞定！

### 2. View Themes / 查看主题

```bash
readmeforge themes
readmeforge themes --lang en   # English version
```

### 3. Auto-Update Setup / 设置自动更新

The generated files include `.github/workflows/readmeforge-update.yml`. Put it in your Profile repo to auto-refresh stats daily. / 生成的文件中包含 `.github/workflows/readmeforge-update.yml`，放到你的 Profile 仓库中即可每日自动刷新。

---

## 📂 Generated Files / 生成的文件结构

```
output/
├── README.md                          # 🌟 Your Profile README / 个人主页
└── .github/
    └── workflows/
        └── readmeforge-update.yml     # 🤖 Auto-update / 自动更新
```

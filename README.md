## 📖 这是什么？

**ReadmeForge** 是一个命令行工具，帮你一键生成惊艳的 **GitHub Profile README**。

只需回答几个简单问题，它就能生成一个专业、美观的个人主页 — 包含统计卡片、技术徽章、贡献图表，甚至还能设置 GitHub Action 自动每日更新！

> 💡 **你的 GitHub Profile 就是你技术名片的第一印象。** 为什么不让它令人难忘？

## ⚡ 快速开始

```bash
# 直接运行（无需安装）
npx readmeforge

# 或者全局安装
npm install -g readmeforge
readmeforge
```

然后按照交互式提示回答几个问题，你的专属 README 就生成好了！

```bash
npm install -g readmeforge
```

### 直接使用（无需安装）

```bash
npx readmeforge
```

---

## 🚀 使用方法

### 1. 交互模式

```bash
readmeforge
```

按提示输入：
- GitHub 用户名
- 展示名称
- 个人简介
- 选择主题
- 技术栈
- 社交链接

### 2. 查看主题

```bash
readmeforge themes
```

### 3. 设置自动更新

生成的文件中包含 `.github/workflows/readmeforge-update.yml`，将它放到你的 Profile 仓库中，即可每天自动刷新统计数据。

---

## 📂 生成的文件结构

```
output/
├── README.md                          # 🌟 你的专属 Profile README
└── .github/
    └── workflows/
        └── readmeforge-update.yml     # 🤖 自动更新工作流
```
